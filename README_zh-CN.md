### 功能

In Falsus 试玩版存在各种 Steam API 校验，因此在试玩版下架以后，未经处理的游戏本体无法正常启动。使用仓库内的 DLL 可绕过校验。

### 快速开始

- 在 [Releases](https://github.com/himlijnn/InFalsusDemoArchive/releases) 下载最新试玩版游戏
- 使用仓库内的 DLL 文件替换游戏本体对应文件
- In Falsus，启动！
